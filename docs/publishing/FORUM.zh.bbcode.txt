[b]VelocityToolbox[/b]

Velocity 运维工具箱：插件热管理、自定义资源包下发与托管、入口域名排查、子服客户端版本限制。

[img]https://raw.githubusercontent.com/polang233/VelocityToolbox/main/assets/logo-256.png[/img]

[url=https://github.com/polang233/VelocityToolbox]项目源码[/url] | [url=https://github.com/polang233/VelocityToolbox/releases]下载插件[/url] | [url=https://github.com/polang233/VelocityToolbox/issues]问题与建议[/url]

[b]运行环境[/b]

[list]
[*]Velocity 4.0 及以上。
[*]Java 25 及以上。
[*]无硬前置。资源包下发已内置。
[/list]

[b]能做什么[/b]

[list]
[*][b]运行时插件管理[/b]：加载、卸载或重载 plugins/ 里的 Velocity 插件。操作前可检查依赖与风险，操作后报告监听器、任务、命令等资源的清理结果。
[*][b]自定义资源包下发[/b]：设置全服默认包，也可按子服、客户端版本和权限分配。支持自托管与外部直链，自托管自动计算哈希；1.20.3+ 可叠加多个包。
[*][b]排查入口域名[/b]：/vtb server hosts 按玩家加入时使用的域名和端口分组。点击入口行展开玩家名与延迟，悬停查看详情。
[*][b]限制子服客户端版本[/b]：为不同子服设置最低/最高版本、允许列表和禁止列表。直接使用 Velocity 的客户端协议 API，无需 ViaVersion。默认关闭，支持配置重载。
[/list]

[b]安装[/b]

1. 从 [url=https://github.com/polang233/VelocityToolbox/releases]Releases[/url] 下载 JAR，放入 Velocity 的 plugins/ 目录。
2. 完整启动代理一次，生成 plugins/VelocityToolbox/config.yml。
3. 给管理员授予 velocitytoolbox.admin，或按下方权限说明细分授权。
4. 使用 /vtoolbox help 或 /vtb help 查看命令。

更新 VelocityToolbox 自身时，替换 JAR 后完整重启代理。

[b]命令[/b]

主命令为 /vtoolbox，别名为 /vtb。普通查询不会刷后台；插件加载、卸载、重载和配置重载只输出简短状态。

[list]
[*][b]/vtoolbox help[/b]：显示帮助。
[*][b]/vtoolbox info[/b]：查看插件、代理、Java、插件数量、子服版本限制和资源包托管概要。
[*][b]/vtoolbox pack list[/b]：列出资源包 URL 和 SHA-1。
[*][b]/vtoolbox server hosts[/b]：按入口域名和端口显示人数，点击展开玩家信息。
[*][b]/vtoolbox reload[/b]：重载语言、配置、子服版本限制和资源包托管。
[*][b]/vtoolbox plugin list[/b]：列出插件名称、版本和作者，悬停查看完整信息。
[*][b]/vtoolbox plugin inspect 插件ID[/b]：检查基本信息、依赖、运行时资源和热卸载风险。
[*][b]/vtoolbox plugin load 文件.jar[/b]：从 plugins/ 目录加载插件。
[*][b]/vtoolbox plugin unload 插件ID[/b]：卸载插件。
[*][b]/vtoolbox plugin reload 插件ID[/b]：卸载后重新加载插件。
[/list]

[b]权限[/b]

velocitytoolbox.admin 可以使用全部命令。

细分授权时，先授予 velocitytoolbox.command，再授予对应子命令权限：

[code]
velocitytoolbox.command.info
velocitytoolbox.command.pack.list
velocitytoolbox.command.server.hosts
velocitytoolbox.command.reload
[/code]

插件管理还需要父权限 velocitytoolbox.command.plugin，以及对应操作权限：

[code]
velocitytoolbox.command.plugin.list
velocitytoolbox.command.plugin.inspect
velocitytoolbox.command.plugin.load
velocitytoolbox.command.plugin.unload
velocitytoolbox.command.plugin.reload
[/code]

例如，只允许检查插件风险，需要同时授予 velocitytoolbox.command、velocitytoolbox.command.plugin 和 velocitytoolbox.command.plugin.inspect。帮助只显示执行者有权使用的命令。

[b]资源包托管与下发[/b]

pack-host 提供本地 HTTP 下载，resource-packs 按子服、版本和权限下发。两个模块默认关闭。
url: "@" 表示不下发材质包，无需托管；@文件.zip 使用自托管文件，均自动计算哈希。外部链接须填真实 hash，用于缓存、更新识别和下载校验。
变体按版本和权限选择，required/prompt 可单独覆盖。版本规则与子服客户端版本限制一致。
支持 1.20.3+ 多包叠加、旧客户端完整单包回退、强制接受、加载状态与重发。
命令为 /vtb pack list、/vtb pack status 玩家、/vtb pack resend 玩家。
细分授权需要 velocitytoolbox.command.pack 和对应的 list、status、resend 动作权限。
入口查询需要 velocitytoolbox.command.server 与 velocitytoolbox.command.server.hosts。
原 packs、vhosts 命令已移动到 pack list、server hosts，旧动作权限需更新。
完整配置与迁移：[url=https://github.com/polang233/VelocityToolbox/blob/main/docs/RESOURCE_PACKS.md]资源包说明[/url]

[b]子服客户端版本限制[/b]

[img]https://raw.githubusercontent.com/polang233/VelocityToolbox/main/assets/screenshot-server-versions.png[/img]

在 config.yml 的 server-versions 段中配置。以下示例只允许指定版本进入 survival，并给 minigame 设置最低版本和禁止项：

[code]
server-versions:
  enabled: true
  servers:
    survival:
      allow: ["1.12.2", "1.20.1"]
    minigame:
      min: "1.18"
      max: max
      deny: ["1.20.2"]
[/code]

[list]
[*]服务器名对应 velocity.toml 的服务器配置，未列出的子服不限制。
[*]min / max 包含边界；max: max 跟随当前 Velocity 支持的最高版本。
[*]allow 非空时只允许列表中的协议；deny 优先拒绝。范围与允许列表必须同时满足。
[*]切服被拒时保留当前子服；首次进入被拒时断开并显示原因。
[*]/vtoolbox reload 或 /velocity reload 重载规则，/vtoolbox info 查看模块状态和各子服的版本范围、允许列表及禁止列表。
[*]配置重载失败保留上次有效规则。首次加载失败时拒绝子服连接，修复后重载恢复。
[/list]

模块默认关闭。版本名必须加引号；共用协议的版本会一起匹配，例如 1.20 和 1.20.1。模块只限制能否进入，跨版本协议转换仍需兼容插件。

完整说明：[url=https://github.com/polang233/VelocityToolbox/blob/main/docs/SERVER_VERSIONS.md]子服客户端版本限制[/url]

[b]热管理说明[/b]

Velocity 4.0+ 没有公开的插件加载和卸载 API。VTB 会阻止卸载仍被其它插件硬依赖的目标，并尽量清理监听器、任务、命令、消息通道、线程池与类加载器，但不能保证任意第三方插件都能安全热卸载。

简单工具插件适合在测试后使用热重载。权限、协议或数据包、连接管理、大型缓存插件更新后，仍建议完整重启代理。

实现说明：[url=https://github.com/polang233/VelocityToolbox/blob/main/docs/maintainer/ARCHITECTURE.md]架构文档[/url]

[b]语言[/b]

language 留空时跟随服务器系统语言，没有对应语言文件时回退中文。也可固定为 zh_cn、zh_tw、en_us，或 lang/ 下的自定义文件名。玩家消息支持 MiniMessage，/vtoolbox reload 会重载语言。
