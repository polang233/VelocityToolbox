# 自用部署参考

此页保存部署参考，不代表当前实服配置。VTB 的通用功能见 [公开模块说明](../MODULES.md)。

## 文件与职责

自用资源包由 ShadiaoVelocity 释放到它自己的 packs 目录。VTB 可以通过 packs-directory: ../shadiaovelocity/packs 使用该目录，并配置 url: "@ShadiaoWorld.zip" 自动取得文件哈希和下载链接。目录与文件名需按实服核对大小写。

VTB 负责托管和下发，不携带或生成自用材质内容。资源包业务内容修改在资源包来源处完成，完成替换后执行 /vtb reload。

## 网络记录

测试环境曾自动选择路由器分配的 192.168.1.10。这是内网地址。公网入口需要实际可达的域名/IP，以及正确的端口映射或反代；本机下载成功不能证明公网玩家可用。

不在这里保存公网管理凭据、口令或下载令牌。需要验证网络时，使用实服实际配置和外部网络重新测试。
