# 维护记录

[文档分类](../README.md) · [源码结构](ARCHITECTURE.md)

本目录记录实现边界和验证状态，供作者与维护者查阅。公开行为在使用指南中说明。

## 构建与验证

在 VelocityToolbox 子目录执行 gradlew.bat build，Linux 使用 ./gradlew build。需要 Java 25。当前版本为 1.3.5；此工作区根目录没有统一 Git 仓库。

修改文档后运行 `python scripts/check_docs.py` 检查链接和代码围栏。

check 覆盖语言键、版本规则、资源包选择/回执、HTTP 限流和传输清理、插件资源归属。实际客户端和完整代理内部热加载仍需实服验证，不能仅凭 build 通过宣称兼容所有客户端。

本机 Windows 无法创建符号链接测试文件，测试会明确输出跳过；普通路径越界、文件变更、HTTP 超时与主动断开已纳入测试。

## 固定防护

公开调参保留总/单 IP 并发、每分钟单 IP 请求额度、下载期限、总/单次带宽和可信反代。
内部固定为总请求 200/s、单 IP 突发 20、IP 记录上限 10000、空闲 300 秒回收、请求大小 16 KiB、隐藏目录、限流重试 2 次且间隔 5 秒。旧配置若仍含这些内部键名，加载会失败并指出键名，删除即可。

这些限制在请求头解析后生效；不要通过插件修改整个 JVM 的 HTTP 系统属性。公网的连接总数和慢请求头保护交给反代或运维启动参数。

## 维护约定

- public-url 留空仍选本机局域网地址。仅明确说明用途，不增加自动公网探测或强制公网模式。
- 单独 @ 是无材质选项；@文件名 才依赖托管。不会生成占位 ZIP。
- 自托管通过查询参数关联限流回执；这不是鉴权或防止下载文件的机制。pack-host 是带限流的公开 HTTP，知道完整 URL 即可下载。
- 状态展示共用 ModuleStatus，新增模块时同步 info、启动、重载和三种语言的键与占位符。
- 公开示例用 survival、rpg 等通用名称。自用部署位置和验证结果在本目录记录，不放入口介绍。
- 保持缓存/配置解析与活跃下载状态边界，修改后测试限流重载、断线、旧回执和叠加顺序。

## 旧预发布配置迁移

备份 config.yml 后调整：全局选项移入 settings；每个包改为列表；file 改为 url: "@文件.zip"，sha1 改为 hash；versions/permission 放入 conditions；default 列表移入 servers.default.packs。子服只保留 packs，required/prompt 放到变体。用版本条件和完整包替代 legacy；required-prompt 统一为 prompt。

原 /vtb packs、/vtb vhosts 分别改为 /vtb pack list、/vtb server hosts，细分权限随之调整。已有配置和语言文件不会自动覆盖。

## 验证范围

Gradle build 包含解析、版本一致性、HTTP、无材质选项、重载、状态回执和命令测试。实服仍需验证 1.15、1.20.3 及当前客户端的无材质切换、多包顺序和后端共存。


## 语言维护

随包语言使用 common/main/plugin/server/pack 五个根节点。旧结构仅识别并提示重新生成，不映射旧键。已有文件不覆盖；当前格式的局部自定义与缺失键回退继续可用。语言消息、前缀和提示状态以一次不可变快照发布。

运行 python scripts/check_lang.py 检查三语键、占位符、重复 YAML 键和 Java 引用，需要 PyYAML。Gradle 的 languageResourceSmokeTest 验证旧结构提示、重新生成、用户文件保留、占位符和繁体系统选择。
